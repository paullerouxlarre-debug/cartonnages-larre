# Cartonnages Larré — site vitrine

Site immersif consacré à l'activité de Cartonnages Larré, entreprise familiale implantée à Bayonne. Le site met en scène la transformation d'une surface imprimée en volume, puis présente les étapes du savoir-faire, les secteurs d'activité et les informations de contact.

## Visiter

Le site est servi par GitHub Pages : https://paullerouxlarre-debug.github.io/cartonnages-larre/

## Sources

Les informations éditoriales proviennent des pages officielles de Cartonnages Larré :

- [Accueil](https://www.cartonnages-larre.fr/fr/)
- [Process](https://www.cartonnages-larre.fr/fr/process.html)
- [Produits](https://www.cartonnages-larre.fr/fr/produits.html)

L'objet graphique et la forme de découpe sont des illustrations conceptuelles. Ils ne représentent pas des produits réels de l'entreprise.
